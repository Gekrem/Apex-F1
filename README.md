# APEX F1 — başlangıç sürümü

Bu klasör, iki dilli (Türkçe/İngilizce) ve mobil uyumlu bir Formula 1 sitesi prototipidir.

## Yerelde açma
`index.html` dosyasına çift tıklayarak tarayıcıda açabilirsiniz. Harici kütüphane veya ücretli servis gerektirmez.

## Ücretsiz GitHub Pages yayını
1. GitHub hesabı açın veya mevcut hesabınıza giriş yapın.
2. Yeni bir public repository oluşturun (ör. `apex-f1`).
3. `index.html` dosyasını repository'nin ana dizinine yükleyin.
4. Repository > Settings > Pages bölümüne gidin.
5. Deploy from a branch seçin; Branch olarak `main`, klasör olarak `/ (root)` seçip Save'e basın.
6. Birkaç dakika sonra GitHub Pages size ücretsiz bir `github.io` adresi verir.

## Önemli notlar
- Haber kartları ve yarış verisi alanları şimdilik örnek içerik/yer tutucudur. Güncel haber veya canlı puan tablosu değildir.
- Canlı veri eklemek için güvenilir ve kullanım şartları uygun bir veri kaynağı belirlememiz gerekir.
- Formula 1, FIA, takımlar ve sponsorların marka/logoları ile fotoğrafları ilgili hak sahiplerine aittir. Bu prototipte resmî logo veya telifli fotoğraf kullanılmamıştır.
- Özel `.com` alan adı zorunlu değildir ve genellikle ücretlidir.
